## Inside MestReNova

MestReNova is a local Windows NMR app with a named mnova desk, a short dataset list, and a clear last handoff. It does not try to replace the rest of the PC. It sits beside spectra you already keep and holds only the dataset that is open now.
The layout stays small on purpose: one desk, one list, one path back. Extra peaks wait for their own title. MestReNova starts with a local profile and does not need a complex account system.

The mnova desk stays on files you already own. Untitled peaks stay off the live list.
